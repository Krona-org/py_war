# 📖 Text Analyzer & Document Indexer (py_war / lab1)

[![C++ Standard](https://img.shields.io/badge/C%2B%2B-23-blue.svg?style=flat-square&logo=c%2B%2B)](https://en.cppreference.com/w/cpp/23)

[![Build System](https://img.shields.io/badge/build-CMake%203.16%2B%20%7C%20Ninja-064F8C.svg?style=flat-square&logo=cmake)](https://cmake.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg?style=flat-square)](LICENSE)

Высокопроизводительный консольный анализатор и индексатор текстовых документов на базе **C++23** и **Windows Memory-Mapped Files (MMF)**.  
Проект спроектирован для мгновенной обработки больших объёмов текста (например, полного текста романа «Война и мир»), построения частотных словарей и инвертированных индексов позиций слов, а также поддерживает **межпроцессную синхронизацию (IPC)** при параллельной записи результатов и **динамическую мультиязычность** с автоопределением раскладки клавиатуры.

---

## 🌟 Ключевые возможности

- ⚡ **Сверхбыстрая обработка через MMF (Memory-Mapped Files)**:
  - Использование Win32 API (`CreateFileMapping`, `MapViewOfFile`) для прямого проецирования файлов в адресное пространство процесса без накладных расходов на чтение через стандартные файловые буферы.
  - Поддержка многобайтовой кодировки **UTF-8** (русский и английский алфавиты) с потоковой нормализацией регистра букв (lowercase) на лету.
  - Нулевое лишнее копирование строк благодаря `std::string_view` и эффективному двустороннему хранилищу `std::deque`.

- 📊 **Частотный анализ и индексация**:
  - Построение словаря частоты встречаемости слов (`WordFrequency`), отсортированного по убыванию популярности.
  - Построение инвертированного индекса (`WordIndex`) с фиксацией всех порядковых позиций каждого слова в тексте документа.
  - Точный замер времени обработки с точностью до долей миллисекунды (`std::chrono::high_resolution_clock`).

- 🔒 **Межпроцессная синхронизация записи (IPC File Synchronization)**:
  - Безопасная конкурентная запись отчетов несколькими одновременно работающими процессами в один и тот же файл.
  - Реализована связка **именованного мьютекса Windows (`CreateMutexA`)** и **разделяемой памяти (`CreateFileMappingA`)**:
    - Первый стартовавший процесс перезаписывает файл (`trunc`).
    - Последующие параллельные процессы выстраиваются в очередь и дописывают свои результаты в конец файла (`append`) без гонок данных и повреждения структуры.

- 🌐 **Умная интернационализация (i18n)**:
  - Автоматическое определение языка интерфейса в реальном времени по активной раскладке клавиатуры Windows (`GetKeyboardLayout`).
  - Переключение раскладки (RU / EN) мгновенно меняет язык меню при следующем отображении.
  - Возможность принудительного задания языка через аргументы запуска (`--lang ru` или `--lang en`).
  - Хранение переводов в структурированных JSON-файлах (`nlohmann::json`).

- 🖥️ **Два режима работы**:
  - **Интерактивный режим**: удобное меню в терминале, системный диалог выбора файла Windows (`GetOpenFileNameA`), настраиваемый вывод топ-N слов и позиций.
  - **CLI / Автоматический режим**: поддержка ключей командной строки для скриптов автоматизации и пакетной обработки.

## 🛠️ Сборка проекта

### Требования
- Компилятор C++ с поддержкой **C++23** (GCC 13+, Clang 16+, MSVC 2022 v19.34+).
- **CMake 3.16** или выше.
- **Ninja** (или Make / Visual Studio Build Tools).
- Операционная система **Windows** (используются вызовы Win32 API).

### Сборка через CMake Presets (рекомендуется)

В проекте настроен `CMakePresets.json`:

```powershell
# Конфигурация Debug
cmake --preset debug

# Сборка Debug
cmake --build --preset debug

# Или сборка Release-версии с максимальной оптимизацией:
cmake --preset release
cmake --build --preset release
```

Готовый исполняемый файл будет находиться в директории `build_debug/lab1.exe` или `build_release/lab1.exe`.

## 🚀 Использование

### 1. Интерактивный режим

Запустите программу без параметров или указав путь к файлу:

```powershell
.\build_debug\lab1.exe
# или
.\build_debug\lab1.exe voina_mir\tom1.txt
```

Если файл не передан, откроется системное диалоговое окно Windows для выбора текстового документа `.txt`.

#### Главное меню программы:
```text
==================================================
Файл: voina_mir\tom1.txt
Размер: 1048576 байт (1.00 МБ)
Время обработки: 14.25 мс
Всего слов в тексте: 125430
Всего уникальных слов: 18210
==================================================
МЕНЮ ДЕЙСТВИЙ:
  1. Показать уникальные слова (по умолчанию топ-10)
  2. Показать топ индексации позиций слов (по умолчанию топ-10)
  3. Записать отчет в файл
  4. Открыть другой файл
  0. Выход
Выберите пункт [0-4]:
```

> **💡 Подсказка:** Переключите раскладку клавиатуры в Windows (`Alt+Shift` или `Win+Space`), и язык меню автоматически обновится!

---

### 2. Пакетный режим командной строки (CLI)

Для автоматизированного запуска и генерации отчетов поддерживаются следующие флаги:

| Флаг | Описание |
| :--- | :--- |
| `-f`, `--file <путь>` | Путь к входному текстовому файлу |
| `-m`, `--mode <0\|1\|2>` | Режим генерации отчета: <br>• `1` — Частотный анализ слов<br>• `2` — Индексация позиций слов в тексте<br>• `0` — Полный комбинированный отчет |
| `-r`, `--result <файл>` | Путь для сохранения результата (по умолчанию: `result.txt`) |
| `-l`, `--lang <ru\|en>` | Принудительный выбор языка отчета (`ru` или `en`) |

#### Примеры команд:

```powershell
# Частотный анализ (режим 1) с сохранением в result.txt
.\build_debug\lab1.exe --file="voina_mir/tom1.txt" --mode=1 --result="freq.txt"

# Индексация позиций (режим 2) на английском языке
.\build_debug\lab1.exe -f "voina_mir/tom1.txt" -m 2 -r "positions.txt" -l en

# Краткий позиционный синтаксис (режим 0 - полный отчет)
.\build_debug\lab1.exe 0 "voina_mir/tom1.txt"
```

## ⚙️ Архитектурные детали

### 1. Механизм Memory-Mapped Files (MMF)
Класс `core::ScanDocs` открывает файл через Win32 API:
```cpp
HANDLE hFile = CreateFileW(...);
HANDLE hMapping = CreateFileMappingW(hFile, ...);
const char* data = (const char*)MapViewOfFile(hMapping, ...);
```
Это исключает копирование данных между ядром ОС и пространством пользователя, позволяя ОС самостоятельно управлять кешированием страниц памяти. 

### 2. Алгоритм потокового разбора UTF-8
Парсер распознает границы слов, знаки препинания и дефисы, на лету выполняя приведение регистра для:
- Стандартных ASCII-символов (`A-Z` $\rightarrow$ `a-z`).
- Двухбайтовых кириллических символов UTF-8 (`А-Я`, `Ё` $\rightarrow$ `а-я`, `ё`).

### 3. IPC и конкурентная запись
Класс `sync::FileSynchronizer` использует:
- Именованный мьютекс `Local\py_war_sync_mtx_<hash>` для эксклюзивного доступа к файлу.
- Именованную область памяти `Local\py_war_sync_map_<hash>`, хранящую счётчик активных процессов `activeCount` и флаг первой записи `hasWrittenFirst`.
- При вызове записи гарантируется атомарность операции и корректное разграничение `std::ios::trunc` / `std::ios::app`.
